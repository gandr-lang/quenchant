# Changelog

All notable changes to quenchant are documented here.

## 0.0.0 - 2026-09-10

Quenchant provides specification-first hardening for Rust: nominal arithmetic, reason-preserving domain types, authored obligations, and compiler and repository gates that make evidence explicit.

The `quenchant` package exposes `quenchant::arith`, `quenchant::shape`, `#[quenchant::spec(...)]`, shape macros, and optional `quenchant::gates`. The default library build is `no_std`. The `anodized` feature selects optional specification instrumentation; both `anodized` and `gates` require `std`. Instrumentation selection does not itself enable violation panics.

The workspace includes a compiler-paired Dylint plugin, invocation-state and adequacy-witness checks, and test-only macro fixtures. Every package uses `Apache-2.0 WITH LLVM-exception`.
